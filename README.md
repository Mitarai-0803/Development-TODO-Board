# Development-TODO-Board

> AI（Claude等）連携機能を備えた、プログラマー向けタスク・バグ管理ツール

ClaudeなどのAI活用に特化した、タスクおよびバグの管理システムです。
バグの発生ファイルや優先度をはじめ、アイデアメモやTodoを一覧で登録・管理できます。
最大の特長は、頻繁にClaudeを利用する開発体験に合わせて追加されたClaude用コピーボタンです。
ボタンひとつで登録情報(Todoとバグ)を一括コピーし、そのままClaudeをはじめとする各種AIに読み込ませるプロンプトとしてスムーズに活用できます。

## 特徴

- タスク（Todo）・バグ（対象ファイル名・）・アイデアやメモを一元管理
- 優先度の設定
- ファイルを一括アップロードしファイル名の候補に登録(入力時に候補に表示)

## 使用技術

- HTML
- CSS
- JavaScript
